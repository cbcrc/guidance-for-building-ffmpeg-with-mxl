# Intel Media Tranport Library

[Intel MTL](https://github.com/OpenVisualCloud/Media-Transport-Library) provides a framwork to
handle IP media streams, like ST 2110-20 (and -40), by passing the kernel stack and exposes the
demuxed media data to apps like ffmpeg.

## Get source

```
git submodule update --init
```

## Setup host

Get NIC PCI@

```
sudo ethtool -i enp42s0f0np0  
driver: ice
...
bus-info: 0000:2a:00.0
```
